# 验证记录

## 自动测试

执行命令：

```powershell
python -m unittest discover -s tests -p test_*.py -v
```

当前结果：45/45 通过。

覆盖范围：

- VISA 驱动和波形转换；
- 权限、参数和严格工具 Schema；
- 规则与模型计划校验、失败回退；
- 设备包注册、结果契约和运行时切换；
- HTTP 页面和 API；
- 周期、低频、高频、直流、噪声、阶跃、削顶和低分辨率模拟场景；
- 单变量实验、写入不确定、恢复验证失败和截图降级；
- 会话、审计和受限实验记忆。
